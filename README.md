# usage-bar

A Claude Code mod that draws one thin, full-width line above the prompt: 5-hour and weekly usage bars with a time-elapsed marker, reset countdown and clock time, a pace hint (on pace, plenty left, or when you would run out), plus context fill and session cost.

## Install

In the Claude desktop app: click **+** next to the prompt box, then **Plugins**, **Add marketplace** with `charlesminh/usage-bar`, then **Add plugin**.

At the prompt of a terminal session:

```
/plugin install usage-bar --marketplace charlesminh/usage-bar
```

From a shell:

```
claude plugin install usage-bar --marketplace charlesminh/usage-bar
```
